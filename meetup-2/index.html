Talk 01

AISecOps for the
Agentic Age

Model, test, monitor. A price-monitoring agent scrapes a competitor's page every night, exactly as it was built to, and one line of fine print on that page walks your cost basis straight back to them. No exploit, just an agent reading content it was told to read. We close the loop live, from a failing security test to an exported guardrail.

Co-founder & Co-CEO · Humanbound

John Rooney

Zyte CDP
managed browser infrastructure

  • Point your existing Playwright or Puppeteer script at a remote Chromium. No rewrite.
  • Zyte supplies the proxy and the fingerprinting. You keep the browser, right down to raw CDP.
  • One connection is one browser, one IP, one cookie jar, so logins, challenges and filled forms carry across steps.

Open-Sourcing Zyte's
Remote Coding Agent
Infrastructure

A new open-source library for running coding agents as remote background jobs. Define an agent declaratively, run it locally or in the cloud, and swap harnesses (Claude Code, Codex) and LLM providers without vendor lock-in, live on Zyte's own spider-writing agents.
